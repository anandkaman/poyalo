# D2 — Database Schema (source of truth)

PostgreSQL 16 + PostGIS + `pgcrypto`. Conventions:
- PK `id uuid` (UUIDv7, generated by the app). `created_at`, `updated_at timestamptz` on every table.
- Money: `*_amount bigint` (paise) + `currency char(3)`. Distance: `*_m int` (meters). Duration: `*_s int` (seconds).
- Geo: `geography(Point,4326)` for points, `geography(MultiPolygon,4326)` for areas. Add a `h3_r8 text` column where useful.
- Enums are Postgres enums (listed in §9). Soft delete is `deleted_at` only where noted.
- Every business table carries **`region_id`** (FK) so it can be filtered and, later, sharded by region.
- High-volume tables are **partitioned by month** (`trips`, `trip_events`, `trip_offers`, `trip_location_points`, `ledger_entries`, `audit_logs`, `notifications`).

## 1. Geography & configuration
```sql
countries(id, iso2 char(2) UNIQUE, name, currency char(3), phone_code, timezone_default, status)
regions(id, country_id FK, code text UNIQUE,          -- 'IN-HYD'
        name, timezone text, currency char(3),
        boundary geography(MultiPolygon) NOT NULL,      -- GIST index
        center geography(Point), status region_status,  -- draft|active|paused
        launched_at)
zones(id, region_id FK, code, name, type zone_type,     -- airport|railway|mall|restricted|custom
      boundary geography(MultiPolygon), priority int, active bool)  -- GIST index
service_types(id, code UNIQUE,                          -- city|outstation (seeded; admin can add e.g. rental later)
              name_i18n jsonb, description_i18n jsonb, requires_schedule bool, active bool)
vehicle_types(id, code UNIQUE,                          -- bike|auto|mini|sedan|suv|suv_xl (seeded defaults, admin-editable)
              name_i18n jsonb /* {"en":"Auto"} */, seats int, icon_url, nav_mode char(1), -- 'd' or 'l' for the Google intent
              sort_order, active bool)
region_service_vehicles(region_id, service_type_id, vehicle_type_id, enabled bool, sort_order,
              PRIMARY KEY(region_id, service_type_id, vehicle_type_id))   -- what a rider sees in each region & tab
-- NOTE: no region/city rows are seeded. Admin creates every region. Seeds = country IN, service types, vehicle types, default settings.
platform_settings(id, scope setting_scope,              -- global|country|region
                  scope_id uuid NULL, key text, value jsonb, updated_by FK admin_users,
                  UNIQUE(scope, scope_id, key))
  -- keys e.g.: dispatch.max_daily_rejections=3, dispatch.offer_timeout_s=15,
  -- dispatch.radius_m=[2000,4000,6000], dispatch.rejection_limit_action='block_until_midnight',
  -- payments.methods=['cash','upi'], app.min_version.driver_android=12, maintenance=false
feature_flags(id, key, scope, scope_id, enabled bool, rollout_pct int, rules jsonb)
```

## 7. Redis keys (hot state)
| Key | Type | Content / TTL |
|---|---|---|
| `drv:geo:{region}:{vehicle_type}` | GEO | idle online drivers |
| `drv:{id}` | HASH | lat, lng, heading, speed, status (idle/offered/on_trip), trip_id, ts. TTL 60 s |
| `drv:{id}:offer` | STRING | trip_id currently offered, TTL = offer timeout (prevents double offers) |
| `trip:{id}:lock` | STRING NX | driver_id that won the accept |
| `trip:{id}:points` | STREAM | GPS trace during the trip |
| `quote:{id}` | HASH | quote cache, TTL 300 s |
| `region:h3:{h3_r7}` | STRING | region_id lookup cache |
| `rl:{actor}:{id}:{route}` | counter | rate limit |
| `idem:{key}` | STRING | stored response, TTL 24 h |
| `surge:{region}:{vt}:{h3}` | STRING | multiplier, TTL 120 s |

## 8. Scale notes
- Partitions are created ahead of time by a monthly `pg_partman` job. Old partitions are detached and archived to R2.
- Read replicas serve admin reports and history lists. The primary handles trips and money.
- If one region gets too big: shard by `region_id` (Citus, or one DB per country). Every query already filters by region.
